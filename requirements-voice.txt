# Optional local voice stack (Whisper ASR, Piper TTS, audio I/O & resampling).
#   python -m pip install -r requirements-voice.txt
# Pulls the runtime set only; add -r requirements-dev.txt for the test suite.
#
# System-level requirements (not installed via pip):
#   - FFmpeg (ffmpeg / libavcodec): mandatory on PATH when decoding compressed
#     audio formats (.mp3, .m4a, .aac, .mp4) through librosa/audioread and
#     recommended for normalizing recordings to 16 kHz mono PCM16 WAV.
#   - PortAudio (libportaudio2 on Linux; bundled in Windows/macOS wheels):
#     required by sounddevice for live 16 kHz duplex microphone/speaker I/O.
#   - SpeexDSP (libspeexdsp1 on Debian/Ubuntu, 64-bit libspeexdsp.dll on Windows):
#     required when PVAI_AEC_ENABLED=true (default); set PVAI_AEC_ENABLED=false
#     for headphones-only use without SpeexDSP.
#   - CUDA 12.x + cuDNN 9.x (optional): only needed when PVAI_ASR_DEVICE=cuda or
#     auto; CPU (int8) is the default with automatic fallback if CUDA is missing.
#   - Note: PyTorch (torch), transformers, and torchaudio are NOT imported or
#     used in this codebase; ASR uses CTranslate2 and TTS uses ONNX Runtime.
-r requirements.txt
