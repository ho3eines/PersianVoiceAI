# راهنمای فارسی برای آزمون ارزش سنجشی

این راهنما به شما کمک می‌کند تا:

1. **فایل‌های لازم** را آماده کنید:
   - `persian_eval_v0_1.jsonl` (12 سناریوی آزمون)
   - `validate_eval.py` (اسکریپت اعتبارسنجی)
   - `score_template.csv` (فایل CSV برای گزارش)

2. **اجرای اسکریپت**:
   - PowerShell را باز کنید و در پوشه‌ای که فایل‌ها قرار دارند، دستور زیر را اجرا کنید:
     ```
     python validate_eval.py persian_eval_v0_1.jsonl score_template.csv
     ```
   - اگر همه چیز درست باشد، خروجی این شکل خواهد بود:
     ```
     VALID: 12 cases
       greeting: fa-001
       numbers: fa-003
       datetime: fa-006
       english_terms: fa-009
       names: fa-012
       zwnj: fa-014
       arabic_chars: fa-017
       long_sentence: fa-019
       spoken: fa-021
       question: fa-024
       command: fa-027
       greeting: fa-040
     ```

3. **بررسی خروجی**:
   - فایل `score_template.csv` به‌روز می‌شود و شامل 12 ردیف با ستون‌های `id`, `category`, `score`, `critical_fail` می‌شود.
   - ستون `score` خالی است و می‌توانید در اینجا نتایج انسانی یا مدل‑محور را وارد کنید.
   - ستون `critical_fail` مقدار 0 دارد؛ مقدار 1 فقط در صورت وقوع یک شکست بحرانی (مثلاً خطای JSON یا تکرار ID) در نظر گرفته می‌شود.

4. **نکات مهم**:
   - اسکریپت فقط از کتابخانه‌های استاندارد Python استفاده می‌کند؛ نیازی به نصب بستهٔ خارجی ندارید.
   - اطمینان حاصل کنید که فایل `persian_eval_v0_1.jsonl` به‌درستی فرمت JSONL (یک JSON در هر خط) دارد.
   - اگر خطایی در حین اجرا دیدید، پیام خطا به شما نشان می‌دهد که در کدام خط مشکل رخ داده است.

با تکمیل این فایل‌ها، مجموعهٔ آزمون فارسی v0.1 آماده برای استفاده در محیط Windows است.
